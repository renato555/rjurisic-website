# rjurisic-website

My personal website: https://renato555.github.io/rjurisic-website/

Plain HTML, CSS and JavaScript with no build step. GitHub Pages serves the `main` branch as it is, so every push updates the site within a minute or two.

## Layout

```
index.html, career.html,      the pages
blog.html, books.html
css/styles.css                colours, fonts, light and dark mode
js/site.js                    theme toggle, shared by every page
js/attractor.js               the strange attractor on the home page
js/bookmap.js                 draws the book map on books.html
js/book-graph.js              map data, generated by tools/book_graph.py
images/                       portrait, favicons, link-preview image
tools/                        book map generator and the book list
docs/custom-domain.md         how to move the site to your own domain
```

## Preview locally

```bash
python3 -m http.server
```

Then open http://localhost:8000.

## Add or change books

The book list and the map are both generated from `tools/books.json`. Edit that file, then run:

```bash
python3 -m venv .venv
.venv/bin/pip install -r tools/requirements.txt
.venv/bin/python tools/book_graph.py
```

It rewrites `js/book-graph.js` and the list in `books.html`. The first run downloads the embedding model (about 400 MB).
